## 1. What went well

1. **The pre-provisioned v1 DDL (Story 1.10) + the permanent migration harness (Epic 1) made Epic-4 persistence additive and low-risk.** Holdings/portfolios/transactions/fx_rates/watchlist_items all existed in v1; Epic 4 added typed CRUD + three narrow `ALTER` steps, never new tables. The "fake future step" test pattern shifted cleanly v4→v5 at 4.7. Three migrations, zero drama. C3's de-risk intent was satisfied *by construction* (the harness already existed).
2. **`core::risk` as a decoupled overlay held under pressure.** Ratchet (4.5), capital-at-risk (4.6) and the trigger rule (4.7) all landed as pure `Decimal` functions beside `core::ssg`; the method fingerprint / golden / determinism gates re-diffed clean across all three. "The risk overlay never weighs down the SSG method" — proven, not asserted.
3. **The 3-layer adversarial review caught a real bug on every code-touching story** — 4.2 below-band silence (product decision #48), 4.3 form-reset-on-refusal, 4.4 freshness/symmetry + the free-plan price-only fetch, 4.5 explicit-set reseed + ticker-change-clears-stop, 4.6 locale-aware percent, and **4.7 the non-atomic sell** (a two-transaction record+mark that could orphan a SELL row and allow a double-sell). None were caught by the green test suites. The 4.7 atomicity catch was a genuine data-integrity bug.
4. **The idempotency-guard lesson (Epic-3 C4) was applied proactively, not in review.** `ensure_portfolio` (idempotent singleton), `set_trailing_stop` (normalized for honest no-op), `mark_sold`/`record_sell` (guarded, then folded atomic), `update_holding` (no-op on identical values). The churn class that bit Epic 3 three times largely did not recur.
5. **The FR13 banned-verb posture gate earned its keep again** — it rejected the imperative *"Vendre"* in 4.7 (relabelled to the noun "Enregistrer une vente"), exactly as it caught "Garder" in 3.4.
6. **Product decisions were surfaced early via structured questions** — reference currency (4.3), EODHD plan workaround (4.4), sell-recording scope (4.7) — keeping stories unblocked instead of stalling mid-dev.

## 2. What was challenging

1. **On-display GO/NO-GO residuals piled up again — C1 slipped a second time.** Every UI-visible story (3.3–3.6, then 4.1–4.7) ships a "manual on-display GO/NO-GO — Guy" residual, and the batch has still not been walked on a real display. The drift the Epic-3 retro predicted in plain words ("the perceptual half drifts under momentum") has now *compounded* across two epics (~11 stories). This is the standing #1 risk.
2. **A foreign-key surprise forced a mid-dev redesign in 4.7.** `transactions.holding_id REFERENCES holdings(id)` made a hard delete-on-sell impossible (it would orphan the sell record's FK). The fix — a soft delete via a new `holdings.sold_at` + a `list_holdings` filter — was sound, but it was discovered by a *test failure*, not at design time. Reading the schema (especially FKs/constraints) before designing the persistence change would have caught it up front.
3. **The EODHD paid-plan decision (C2) is still open.** It was engineered-around in 4.4 (a price-only `/eod` fetch that works on the free plan), but live fundamentals validation stays blocked — and Epic 5's "confront" mode depends on a post-decision price-history cache sourced via the same refresh path.
4. **A small product-decision backlog is accumulating** — #48, #49, #58, #60, #61 — UX/product calls only Guy can make, drifting unresolved.

## 7. Key takeaways

1. **Infrastructure built once keeps paying** — the v1 pre-provisioned schema + the Epic-1 migration harness made three Epic-4 migrations boringly safe. Build the harness, append the steps.
2. **Additive-by-construction architecture wins** — a decoupled `core::risk` overlay added trailing stops, capital-at-risk and triggers with zero impact on the frozen SSG method.
3. **3-layer review and headless tests are complementary, not redundant** — the review caught a data-integrity bug (4.7 atomicity) the green tests could not. Keep it the default.
4. **A human-gated action item that isn't a hard gate will slip** — C1 (on-display GO/NO-GO) drifted twice. Epic 5 makes it blocking (D1).
5. **Read the schema before you design the write** — the 4.7 FK surprise turned into a clean soft-delete, but only after a test failure. Codified as D3.
